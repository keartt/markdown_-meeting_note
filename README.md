# 📝 Simple Markdown → PDF 회의록 생성기

마크다운(`.md`) 파일을 기반으로  **깔끔한 회의록 PDF를 자동 생성하는 Node.js 스크립트**

- A4 기준 최적화 레이아웃
- 표 / 리스트 / 제목 스타일 적용
- 페이지 분리 및 줄 잘림 방지


## 🚀 Features

- Markdown → HTML → PDF 자동 변환
- h2(중제목) 단위 페이지 레이아웃 유지
- 테이블 헤더 제거 + 좌측 컬럼 강조
- 숫자/리스트 마진 최적화


## How to use
📦 Install 

```bash
npm install marked puppeteer cheerio
```

▶️ start

```bash
node meeting.js ${fileNm}

node meeting.js sample
```

👉 실행 시:

./md/sample.md → ./pdf/sample.pdf 생성


📁 프로젝트 구조
```tree
project/
 ├── md/        # 입력 마크다운 파일
 ├── pdf/       # 생성된 PDF 파일
 ├── meeting.js
 ├── package.json
 └── .gitignore
```
